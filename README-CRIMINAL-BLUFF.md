# Криминальный Блеф

Телеграм-бот для мини-игры "Криминальный Блеф" - увлекательная игра в детектива, где вам предстоит разгадывать запутанные истории и определять, кто говорит правду, а кто блефует.

## Особенности

- Увлекательные истории о преступлениях с множеством деталей
- Система рейтингов и лидерборды
- Механика определения правды и лжи
- Кастомный интерфейс для Telegram Mini Apps
- Поддержка онлайн и офлайн режимов

## Технический стек

- Node.js и Express для API
- MongoDB для хранения данных
- Redis для кэширования
- Telegram Bot API и Mini Apps для интерфейса
- Railway для деплоя

## Инсталляция и запуск

### Предварительные требования

- Node.js 18+ и npm
- MongoDB
- Redis (опционально)

### Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/your-username/criminal-bluff.git
   cd criminal-bluff
   ```

2. Установите зависимости:
   ```
   npm install
   ```

3. Настройте переменные окружения:
   ```
   cp .env.example .env
   ```
   Отредактируйте `.env` файл, указав необходимые значения.

4. Запустите сервер в режиме разработки:
   ```
   npm run dev
   ```

### Деплой

Проект готов к деплою на Railway:

1. Создайте проект на Railway
2. Добавьте сервисы MongoDB и Redis
3. Подключите репозиторий GitHub
4. Настройте переменные окружения

## Использование

1. Найдите бот в Telegram: [@criminal_bluff_bot](https://t.me/your_bot_name)
2. Нажмите "Старт"
3. Следуйте инструкциям бота для начала игры

## Разработка

### Структура проекта

```
/src
  /config      - Конфигурация приложения
  /controllers - Контроллеры API
  /middlewares - Промежуточные обработчики 
  /models      - Mongoose модели
  /routes      - Маршруты API
  /services    - Бизнес-логика
  /telegram    - Интеграция с Telegram
  /utils       - Вспомогательные утилиты
/public        - Статические файлы для Mini App
```

### Команды

- `npm run dev` - Запуск в режиме разработки
- `npm start` - Запуск в продакшн-режиме
- `npm test` - Запуск тестов
- `npm run lint` - Запуск линтера
