# Техническое задание для Telegram Mini App "Криминальный Блеф"

## 1. Общее описание проекта

Криминальный Блеф - это игра-викторина в формате Telegram Mini App, где пользователи угадывают ошибки преступников в реальных историях. Игроки читают короткие криминальные истории и выбирают, какая деталь является ошибкой преступника.

## 2. Технологический стек

- **Frontend**: HTML5, CSS3, JavaScript (без фреймворков для простоты)
- **Backend**: Node.js, Express.js
- **База данных**: MongoDB
- **Кэширование**: Redis (для рейтингов)
- **Telegram интеграция**: node-telegram-bot-api

## 3. Структура базы данных

### 3.1 Коллекция `stories`

```javascript
{
  id: String,            // уникальный идентификатор
  title: String,         // заголовок истории
  content: String,       // текст истории
  difficulty: String,    // "easy", "medium", "hard"
  category: String,      // "robbery", "theft", "fraud", "other"
  mistakes: [             // массив ошибок в истории
    {
      text: String,      // текст варианта ответа (ошибка)
      correct: String    // объяснение, почему это ошибка
    }
  ],
  timesPlayed: Number,    // количество сыгранных раз
  correctGuesses: Number, // количество правильных ответов
  createdAt: Date         // дата создания
}
```

### 3.2 Коллекция `users`

```javascript
{
  telegramId: String,     // ID пользователя в Telegram
  username: String,       // Имя пользователя
  firstName: String,      // Имя
  lastName: String,       // Фамилия
  stats: {                // Статистика пользователя
    totalGames: Number,   // Общее количество игр
    correctAnswers: Number, // Количество правильных ответов
    totalScore: Number,   // Общее количество очков
    totalTime: Number,    // Общее время в игре (мс)
    averageTime: Number,  // Среднее время ответа (мс)
    accuracy: Number,     // Процент правильных ответов
    currentStreak: Number, // Текущая серия правильных ответов
    maxStreak: Number     // Лучшая серия правильных ответов
  },
  achievements: Array,    // Массив полученных достижений
  createdAt: Date,        // Дата создания профиля
  lastActive: Date        // Дата последней активности
}
```

### 3.3 Коллекция `leaderboard`

```javascript
{
  userId: ObjectId,      // ссылка на коллекцию users
  score: Number,         // количество очков
  period: String,        // "daily", "weekly", "all-time"
  updatedAt: Date        // дата обновления
}
```

## 4. Игровой процесс

- Всего игр


### 5.3 Рейтинговые эндпоинты

```
GET /api/leaderboard/daily - дневной рейтинг
GET /api/leaderboard/weekly - недельный рейтинг
GET /api/leaderboard/all-time - общий рейтинг
```

## 6. Система начисления очков

- Правильный ответ: +100 очков (базовые очки)
- Бонус за скорость: до +50 очков (рассчитывается по формуле)
  - Максимальное время на ответ: 15 секунд
  - Бонус = MAX_SPEED_BONUS * (1 - (timeSeconds / MAX_ANSWER_TIME))
- Серия правильных ответов:
  - 3 подряд: +50 бонус
  - 5 подряд: +100 бонус
  - 10 подряд: +250 бонус

Окончательная формула расчета очков:
```
totalScore = baseScore + streakBonus
baseScore = правильный ответ ? (100 + speedBonus) : 0
speedBonus = MAX_SPEED_BONUS * (1 - (timeSeconds / MAX_ANSWER_TIME))
```

## 7. Достижения

- "Новичок" - сыграть первую игру
- "Эксперт" - 10 правильных ответов подряд
- "Мастер дедукции" - 100% точность в 5 играх подряд
- "Скоростной детектив" - правильный ответ за 3 секунды
- "Серийный игрок" - 100 сыгранных игр
