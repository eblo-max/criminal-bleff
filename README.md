# Криминальный Блеф - True Crime Edition

![Криминальный Блеф](public/img/promo-screenshot.jpg)

## О проекте

"Криминальный Блеф" - это увлекательная мини-игра для Telegram, которая проверит вашу интуицию и знания в области криминалистики. Пользователям предлагается прочитать истории о преступлениях и определить, что в них правда, а что вымысел.

### Особенности

- 🕵️‍♂️ **Увлекательные истории** о настоящих и вымышленных преступлениях
- 🎮 **Атмосферный дизайн** с эффектами глючности и тематическими элементами
- ⏱️ **Ограниченное время** на принятие решения для увеличения азарта
- 📊 **Таблица лидеров** для соревнования с другими игроками
- 🏆 **Система достижений** для поощрения активных игроков
- 📱 **Интеграция с Telegram Mini Apps API** для бесшовного пользовательского опыта
- 🔄 **Offline-режим** для игры без подключения к интернету

## Технический стек

- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Интеграция: Telegram WebApp API
- Хранение: localStorage для кеширования данных
- Анимации: CSS3 анимации и transitions
- Оптимизация: Service Workers для offline-режима

## Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/criminal-bluff.git
   ```

2. Перейдите в директорию проекта:
   ```
   cd criminal-bluff
   ```

3. Запустите локальный сервер (с помощью Live Server в VS Code или другим способом)

4. Для разработки и тестирования в Telegram, используйте [Telegram Mini Apps Dev Tools](https://core.telegram.org/bots/webapps#testing-mini-apps)

# Запуск приложения в продакшен-режиме

Для запуска приложения в продакшен-режиме выполните следующие шаги:

## 1. Подготовка к запуску

Перед запуском убедитесь, что у вас правильно настроен файл `.env` со следующими переменными:

```
NODE_ENV=production
MONGO_URL=mongodb://your-mongodb-connection-string
API_URL=https://your-api-url
```

## 2. Инициализация базы данных

Приложение требует начальной инициализации базы данных. Для безопасной инициализации в продакшен-режиме используйте специальный скрипт:

```bash
node src/scripts/initProductionData.js
```

Этот скрипт безопасно инициализирует базу данных, создавая только недостающие структуры:
- Проверяет и создает начальные игровые истории
- Проверяет и создает структуру таблиц лидеров (daily, weekly, all-time)

## 3. Запуск сервера

После инициализации базы данных запустите сервер в продакшен-режиме:

```bash
node src/scripts/runServerProduction.js
```

или

```bash
NODE_ENV=production node src/server.js
```

## 4. Проверка работы

После запуска сервер будет доступен по указанному порту (по умолчанию 3000).
Проверьте доступность сервера, открыв в браузере:

```
http://localhost:3000/health
```

Должен вернуться статус `{"status":"ok"}`

## Примечания по безопасности

1. В продакшен-режиме автоматически применяются следующие настройки:
   - Более строгие CSP (Content Security Policy) заголовки
   - Дополнительные меры безопасности для заголовков HTTP
   - Ограничения CORS для разрешенных доменов

2. Логи в продакшен-режиме сохраняются в директорию `logs/`
